# ESP PClock

> 使用到的硬件：
> 
> [Firebeetle 2 Board ESP32-P4](https://wiki.dfrobot.com/SKU_DFR1172_FireBeetle_2_Board_ESP32_P4) (16MB QIO FLASH)
> 
> Wi-Fi (ESP32-C6) + NTP + RTC ([system time - ESP32](https://docs.espressif.com/projects/esp-idf/zh_CN/v5.5.1/esp32/api-reference/system/system_time.html#sntp))
> 
> LVGL +  [WLK2802MIPI](https://github.com/sfxfs/esp_lcd_st7701_WLK2802MIPI) + PCA9536 (for backlight control)

本项目基于 ESP32-P4 和 MIPI 屏幕 实现了类 PSP GO 待机界面的联网时钟
